# ABGX360 GUI

A Linux/Windows GUI for abgx360, the Xbox 360 ISO stealth checker — verify your own disc images against the database with a queue, full logging, and first-run dependency setup.

## Credits

- **abgx360** — originally created by **Seacrest**; this GUI builds on the **Hadzz** fork (v1.0.7). All verification logic and credit for it belongs to the abgx360 authors.
- Disc images are the user's own; no game data is included or distributed.
